# Symptom Log

A private, offline-first tracker for IBS-D, fibromyalgia, depression, anxiety, undiagnosed symptoms and daily life (meals, sleep, walks, meds, light, screen time, leisure, relaxation, self-care). It connects what you do to how you feel and builds a brief for doctor's visits.

**Your data never leaves your phone.** Entries are stored on the device (IndexedDB). This repository only holds the app's code.

## Install on iPhone
1. Open the app's address in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Open it from the Home Screen icon from now on (that copy keeps your data).

## Back up
History → **Back up to Files** saves a backup file to Files or iCloud Drive. Restore it with **Choose backup file**.

## Updating
Publishing new files here updates the app. Bump `VERSION` in `sw.js` so installed copies pick up the change; the app shows an **Update** button.
